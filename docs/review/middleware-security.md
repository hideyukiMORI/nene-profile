# ミドルウェア・セキュリティ自己レビュー

認証・認可・テナント分離・ミドルウェアに触れる変更に使用する。

ソースポリシー: `docs/development/backend-standards.md`, [ADR 0006](../adr/0006-multi-tenancy-and-roles.md).

## 認証

- [ ] Admin 変更ルートに JWT Bearer 認証が設定されている (`BearerTokenMiddleware`)
- [ ] 認証なしで変更操作を実行できるルートがない
- [ ] `GET /health` のみ認証不要; 他のパブリックエンドポイントを追加した場合は理由を PR に記載

## 認可（ケイパビリティ）

- [ ] 各ルートに必要なケイパビリティが `CapabilityMiddleware` で設定されている
- [ ] ケイパビリティ値が `terminology.md` の登録済み値と一致する
- [ ] superadmin のみが組織管理操作を実行できる (`manage_organizations`)
- [ ] member ロールがユーザー管理・設定変更を実行できない

## テナント分離

- [ ] 全クエリで `organization_id` によるスコーピングがある
- [ ] superadmin 以外がクロステナントデータにアクセスできない
- [ ] per-request `organization_id` が `OrgResolverMiddleware` 経由で解決されている
- [ ] `RequestScopedHolder` を使用して resolved org を引き回している（直接 `$_SERVER` 等から取得していない）

## 入力バリデーション

- [ ] ユーザー入力のすべてをバリデーションしている（パスパラメータ、クエリ、ボディ）
- [ ] SQL インジェクション対策: プリペアドステートメント / バインドパラメータ使用
- [ ] ファイルアップロード: MIMEタイプ・サイズ・ファイル名をバリデーション済み
- [ ] パスバーサル: アップロードパス・ダウンロードパスが制御外ディレクトリに到達しない

## エラーレスポンス

- [ ] スタックトレース・SQL・内部ファイルパス・シークレットが公開エラーに含まれていない
- [ ] 認証エラー: 401 Unauthenticated（ユーザー存在を暗示する情報を返さない）
- [ ] 認可エラー: 403 Forbidden（対象リソースの内容を暴露しない）

## ファイルアクセス（Profile 固有）

- [ ] CSV ファイルが `public_html/` 配下に保存されていない
- [ ] ファイルパスがオペレーター設定の基底パス外に出ていない
- [ ] 原本ファイルが直接 HTTP 経由で提供されていない（エクスポートエンドポイント経由のみ）
