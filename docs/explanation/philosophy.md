# Philosophy — NeNe Profile

**NeNe Profile** — *Map any bank CSV. One standard output.*

## Beliefs

1. **Bank formats change** — operators need editable mappings, not vendor lock-in.
2. **Parsing ≠ reconciliation** — separate repos, separate failure domains.
3. **Integer cents end-to-end** — no float amounts in transforms.
4. **Presets are templates** — community/shareable, not secrets.
