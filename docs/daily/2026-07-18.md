## ① CI paths フィルタ除去＋job 名一意化（#117 / PR #118・**merged** `0237044`）

- 背景（伝聞=hub 依頼文）: フリート一斉施錠で profile は両 CI が `paths:` フィルタ持ちのため唯一 deferred。フィルタ持ちのまま required にすると、フィルタに掛からない PR（docs のみ等）で context が報告されず永久ブロックになる。
- 変更（実測）: backend-ci.yml / frontend-ci.yml の `paths:` を push / pull_request 両方から除去し常時実行化。job 名 `check`（両ワークフローで重複）→ `backend-check` / `frontend-check` に rename。steps 不変・`e2e` は既に一意のため不変。diff は 2 files / +2 −30。
- CI（実測）: backend-check 34s / frontend-check 48s / e2e 1m13s 全緑 → squash self-merge。
- 施錠（伝聞=hub 報告）: merge SHA 一報後、hub が required 施錠を実行。required=backend-check/frontend-check・enforce_admins:true・フリート 15/16 達成。e2e は flakiness 観測後の締め増し枠として今夜は required に入れない、とのこと。
